# qe-test-plan-kit

Design test plans and scenarios - functional coverage, manual test plans, and business-language Gherkin.

**Reach for this kit when:** you need to decide what to test.

## What's inside

| Type | Name | What it does |
| --- | --- | --- |
| Skill | `cucumber-component-test-writer` | Component-level test plans in Gherkin, written as business behaviour, with the technical detail pushed out of the steps and into a mock inventory. |
| Skill | `manual-test-plan-writer` | Manual test cases and plans for a feature, field, state machine, batch job, UI behaviour or cross-service flow. |
| Skill | `pcsa-md-functional-test-plan` | Functional test plans for PCSA-MD features as `.feature` drafts, ready to implement or to use as a spec. |

## Layout

| Directory | Holds |
| --- | --- |
| `skills/` | One directory per skill, each with a `SKILL.md` |
| `agents/` | One `.md` file per agent |
| `commands/` | One `.md` file per slash command |
